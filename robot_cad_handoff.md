## Goal and rules

User rules: brief answers, one step at a time, targeted diffs not full rewrites. CAD: Onshape from STEP files I generate with CadQuery. Sim: ROS 2 Jazzy + Gazebo Harmonic. Software: existing ~/pet_face stack (app, brain, voice, speak, behavior) + ~/pet_ws/src/pet_robot.

## CAD method
- One global frame for every part (mm, Z up, Y forward, chassis plate bottom z=0, ground z=-45). Every part's Origin = global origin.
- Onshape: Mate connector on Origin in each Part Studio, Fastened mate Origin to Origin (first clicked part moves). Never use face mates.
- Pan axis: Z at x=0,y=0 (neck_column_v2 Revolute to pan_servo_v2, +-80). Tilt axis: X at z=251.35 (head_bracket Revolute to tilt_servo, +-35; connectors Origin + translation Z 251.35 + rotation Y 90 on both).
- Groups (what each moving link contains):
  - Static (base_link): Chassis, both motors, mid plate, neck mast, pan servo, 3 deck sleeves, battery tray, electronics deck, controller tray, 2 cliff mounts. Shell group (below) is also static. Fasten shell parts directly to Chassis Origin.
  - neck_yaw (pans): neck_column_v2, pan_horn, tilt_servo, pivot_post. Fasten to neck_column Origin.
  - head (tilts): head_bracket, tilt_horn, pivot_arm. Head shell group fastens to head_bracket Origin.
  - Wheels / steer_fork / front_wheel are separate links.
